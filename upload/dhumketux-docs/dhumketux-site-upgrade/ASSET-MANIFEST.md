# Asset Manifest

## 1. Priority Asset Types

### Tier 1 — Must Have

- hero rocket imagery/video
- flagship project renders
- propulsion close-ups
- testing imagery
- team image
- milestone/award imagery

### Tier 2 — Strong Enhancers

- workshop/lab details
- launch rig photos
- UAV flight imagery
- satellite/CubeSat imagery
- engineering diagrams
- mission-control visuals

### Tier 3 — Optional

- abstract orbital textures
- star-field backgrounds
- abstract trajectory graphics
- subtle atmospheric footage

## 2. Image Hierarchy

Prefer in this order:

1. DhumketuX-owned hardware photographs
2. DhumketuX-approved renders
3. DhumketuX-approved team/program photos
4. licensed third-party media
5. generated/decorative imagery only for non-factual atmosphere

## 3. Image Cropping

Design against these standard aspect ratios:

- 16:9 hero
- 4:3 editorial
- 3:2 documentary
- 1:1 technical card
- 9:16 optional mobile story asset

Never crop away essential engineering features from a technical image.

## 4. Alt Text

Alt text must describe the visual purpose, not dump marketing language.

Good:

`DhumketuX rocket prototype mounted on a launch support structure during testing.`

Avoid:

`The most revolutionary rocket from Bangladesh changing humanity forever.`

## 5. Licensing

Every non-owned asset needs a documented license or permission before production.

Press-site images discovered during research are references, not automatically production-safe assets.

## 6. Research Image References

A search of current/public DhumketuX imagery surfaces real rocket prototypes, team/project imagery and Nazrul/Bidrohi visual references. Treat these as visual references until rights are confirmed.
