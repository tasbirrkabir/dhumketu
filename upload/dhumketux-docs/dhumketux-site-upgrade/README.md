# DhumketuX Website Upgrade

A premium website redesign concept for **Dhumketu Exploration Technologies Limited (DhumketuX)**.

## Project Intent

Turn the existing information-heavy website into a **credible, cinematic, engineering-first aerospace experience** that communicates:

- Bangladesh-built aerospace capability
- Rockets, propulsion, UAVs, satellites, avionics and mission systems
- A long-term space-infrastructure vision
- Proof through projects, milestones, team, media and technical work
- Clear paths for partners, students, investors/sponsors, talent and launch customers

This is a **concept/demo website** intended to show DhumketuX what a modern digital experience could look like. Do not imply that this is an official DhumketuX rebuild unless explicitly authorized.

## Current Site Snapshot

The live site currently exposes a very large navigation tree spanning Aerospace, Aviation, R&D, About, Programs, communities, student initiatives, shop and launch-booking flows. The homepage also surfaces launch vehicles, milestones, statistics, R&D technologies, satellites, drones/aircraft, human-spaceflight, collaboration, sponsors/donations and FAQs. See `docs/IA.md` for the proposed simplification.

The current homepage also appears to contain unrelated injected/spam links near the bottom of the page. This must **not** be carried into the redesign. See `docs/TECH-SPEC.md` and `docs/QA.md`.

## Recommended Build Principle

**Build the experience around evidence, not decoration.**

Aerospace aesthetics should create atmosphere, but real projects, technical specifications, milestones, imagery, data and organizational credibility should do the persuasion.
