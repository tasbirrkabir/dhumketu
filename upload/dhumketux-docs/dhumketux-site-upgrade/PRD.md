# PRD — DhumketuX Website Upgrade

## 1. Product Summary

Create a premium concept website that positions DhumketuX as a serious aerospace R&D organization originating from Bangladesh, while making its projects and opportunities dramatically easier to understand.

The current site contains substantial material but spreads it across a very broad navigation model. The redesign should turn that breadth into a coherent story.

## 2. Primary Experience Goal

Within the first 10–15 seconds, a visitor should understand:

> **DhumketuX builds aerospace systems from Bangladesh — rockets, propulsion, UAVs, satellite-related systems and the infrastructure around them.**

Then the visitor should naturally move toward evidence:

**What they build → How they build → What they have achieved → What they are building next → How I can engage.**

## 3. Audiences

### A. Aerospace / engineering audience
Wants projects, specifications, architecture, R&D and evidence.

### B. Universities / students
Wants programs, DBF, virtual labs, internships and collaboration pathways.

### C. Partners / sponsors / institutions
Wants credibility, capabilities, team, milestones and a clear partnership route.

### D. Media / general public
Wants a simple story, visual proof and milestone timeline.

### E. Talent
Wants team culture, open roles, programs and meaningful engineering work.

## 4. Business Outcomes

The website should help DhumketuX:

- increase perceived credibility
- make complex technical work understandable
- surface flagship projects
- convert visitors into collaboration conversations
- recruit talent and students
- improve media/shareability
- provide a canonical source of project information

## 5. Design Direction

### Keywords

**Orbital / Engineered / Cinematic / Precise / Indigenous / Ambitious / Human**

### Avoid

- generic dark-tech dashboards
- neon cyberpunk overload
- stock-space imagery as the main visual language
- excessive gradients
- fake telemetry
- “AI startup” aesthetics

## 6. Homepage Narrative

### Section 01 — Hero

A full-bleed cinematic aerospace visual with a restrained technical overlay.

Suggested message:

**BUILDING AEROSPACE FROM BANGLADESH.**

Supporting line:

`Rockets. Propulsion. Autonomous systems. Space technologies.`

Primary CTA: `Explore Our Work`

Secondary CTA: `Our Vision`

Optional small proof marker: `Bangladesh • Aerospace R&D`

### Section 02 — Proof Strip

A short, high-contrast evidence band using only approved facts.

Examples from the current site content include team size, founding year, tests and publications. These values must be revalidated before final use.

### Section 03 — Flagship Work

Feature 3–4 major projects with large imagery and short technical summaries.

Recommended initial grouping:

- Bidrohi / launch vehicle
- Agni Bina / solid propulsion
- Boson / liquid propulsion
- Nazrul series / SSLV

### Section 04 — Capability System

Explain the engineering stack rather than presenting a flat list:

`Flight Systems → Propulsion → Avionics → Telemetry → Autonomy → Ground Systems → Testing`

### Section 05 — Mission / Milestones

A horizontal or vertical timeline showing the organization's development.

Use source-controlled years/events only.

### Section 06 — Vision

Make the long-term ambition a visual statement. The current vision page describes space billboard/orbital media, Earth observation and space-based internet/connectivity ambitions. Present these as future-facing pillars, clearly marked as vision.

### Section 07 — Human Layer

Show the people behind the machines: team, leadership, students and collaborators.

### Section 08 — Collaboration

Clear routes:

`Partner → Sponsor → University → Student → Talent`

### Section 09 — Latest / Media

A clean editorial rail for news, articles, launches and announcements.

### Section 10 — Closing CTA

Strong closing statement and one simple action.

Example:

**THE NEXT CHAPTER STARTS HERE.**

`Build with DhumketuX →`

## 7. Functional Requirements

### Must Have

- responsive navigation
- mobile menu
- project listing
- project detail template
- capability pages/sections
- milestone timeline
- media/article cards
- collaboration CTA
- careers/program pathways
- accessible footer
- metadata + OG tags

### Nice to Have

- cinematic page transitions
- interactive project filtering
- animated technical diagrams
- cursor micro-interactions on desktop
- scroll-linked visual storytelling

### Demo-Only Features

- simulated flight/telemetry visualizations, only when explicitly labelled
- speculative future mission visuals, clearly identified as concept art

## 8. Success Criteria

A viewer unfamiliar with DhumketuX should be able to answer all of these after visiting the homepage:

1. What is DhumketuX?
2. What does it build?
3. What evidence shows it is real?
4. What is the long-term vision?
5. How can I engage with the organization?

## 9. Constraints

- factual accuracy over marketing flourish
- respect existing brand identity
- no unauthorized third-party logos/assets
- no fabricated claims
- no fake live systems
- preserve clear English terminology; add Bangla where it improves cultural storytelling rather than duplicating every block
