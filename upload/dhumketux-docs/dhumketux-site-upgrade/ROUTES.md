## Project Detail Template

Each project detail page should follow:

```text
Hero
→ Snapshot metrics
→ Why it exists
→ Architecture / system overview
→ Development status
→ Images / testing
→ Related projects
→ CTA
```

Avoid giant text walls. Use progressive disclosure.
